# Incremental Game Tier List

Create your own incremental-game rankings. Drag games into tiers, view available community scores, and export PNG, CSV, or JSON.

Rankings and display preferences save in your browser. Save to keep a copy or move your rankings to another browser. Load restores an exported list. New visitors start with every game unranked.

Load miserable_duck's Rankings applies the optional published tier preset. The preset contains tiers and ordering only. The unranked panel has three columns, scrolls independently, and can be minimized. CSV and PNG exports include ranked games only; JSON keeps the complete list for restoring it later.

This is a static site: index.html, data.json, and covers/. Enable GitHub Pages from the main branch and the repository root.

Game artwork and statistics are sourced from the linked game listings and stores. Scores are snapshots; only available values are displayed. Apple and Google ratings use the US storefront.
